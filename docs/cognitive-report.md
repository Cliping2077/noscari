# Noscari Baby Cognitive Model Research — 第一轮结果

2026-10-19，软件 0.1.0a4。CPU、无外部 API、固定协议与 5 个独立训练种子。

## 结论与研发决定

可训练 GRU 确实从实际反馈改变了持续状态，并在新任务上形成不同的方法偏好。
但它没有胜过显式统计＋MLP，也没有解决混乱分类下的负迁移问题。本轮不将它
提升为默认核心，不继续堆叠新模块来追求成功；作为可复现的实验组件保留。

原来 59%→76%、规则记忆同为 76%、混乱分类 63%→58% 的记录和 alpha 1–3
发布包均保留。下面是另一种连续任务协议，不能把不同协议的成功率连成成长曲线。

## 审计与唯一结构改造

旧核心的参数学习主要是固定特征上的方法收益估计；技能匹配、遍历、问题模板、
候选生成、身份字符串和事件持久化主要由工程规则实现。旧恢复实验直接提供情境
配置的教师可靠性。本轮改用严格 PublicState，完全没有教师可靠性、环境类型、
正确路径、变化点等字段。环境真值只在评分器中使用，任务 ID 不作为模型特征。

本轮唯一机制是反馈驱动的 GRU 持续状态：11 维实际反馈 → 24 维状态；结合
13 维可见情境，预测三个动作的收益与即时成功概率。其 4,078 个参数在离线
反馈回放中训练。对照 MLP 4,086 参数，统计＋MLP 4,102 参数；线性对照 156 参数。
设计受已有循环控制和快慢学习研究启发，不声称发明新的学习原理。
理论、机制审计及原始文献见 [研究设计](cognitive-research.md)。

明确区分四种东西：JSONL 具体经历；EMA/均值/次数的显式统计；由训练过的
GRU 更新的激活状态；梯度更新的慢参数。反馈改变前三者，只有 learn 改变参数。
测试权重冻结，状态和统计仍从各策略自己的实际反馈更新。状态跨同一软件会话的
任务保持，新会话由宿主明确重置；尚无自主识别上下文切换或通用自我模型。

候选从第一步就同时包括可执行的遍历、语义选择和求助，不等待语义失败才出现。
这是步骤之间的候选竞争，不是并发执行器。问题措辞、自由语言教学和新技能发现
不属于本轮；语义匹配、遍历、单一模拟教师仍为提供好的能力。

## 信息、训练与评估隔离

每个种子 16 个 A 会话＋48 个 B 会话，每会话 16 任务，共 5,120 个训练任务。
共享探索策略只执行随机选择的合法动作；没有未选动作的奖励标签，也没有教师
准确率监督。A 只含规律环境，B 含混乱、部分规律和中途变化；各网络用相同数据。
训练目标是该行为策略的任务内 Monte Carlo 回报，不能当成最优 Q 值。

在训练前封存与训练集不重叠的 1,920 个新任务，覆盖 80 个软件会话；同一会话
内的任务共享潜在情境，不能视为独立统计样本。每种完整策略有相同
任务、操作预算和可见信息。11 个最终策略＋4 个 A 阶段检查点，共 28,800 次
测试执行。测试任务不参与梯度训练。网络/统计策略有固定 5% 随机探索，这不是
学得的内在动机；原遍历和规则记忆基线为确定性策略，因此与它们比较时也包含
探索的代价。主要比较的 GRU 与统计＋MLP 都有相同探索设置。

源码、协议、数据哈希在 manifest.json；两份运行配置一致性检查已通过。教师
准确率 .9/.4、回应意愿 .9/.5、查询成本 1/3、权限与布局独立变化；学习器只看到
成本/权限及实际回应和成功/失败。拒绝不会永久撤销以后任务的求助资格。

主要指标是 GRU 减去统计＋MLP 的配对种子平均效用差：**−0.005417**；
5 种子 t 区间 **[−0.012650, +0.001817]**。区间跨零，既不能宣称 GRU 有优势，
也不能据此证明严格等效。5 个种子仍是有限证据，不能当成独立实验室复现。

这支持训练对当前网络行为和任务表现的影响；不能据此证明 GRU 比更简单方法必要。
固定规则记忆总体为 83.80%，说明本任务族中简单语义尝试仍很有竞争力。

规律环境后半段，GRU 的语义首选率为 88.33%；混乱环境后半段为 35.83%。
把同一已训练 GRU 在每个任务开始时清空状态，这两个比例变为 70.42% 和 63.33%。
可见跨任务反馈状态确实影响了相同类型新任务的选择。显式统计＋MLP 分别为
93.33% 和 22.92%，其条件区分更明显。该描述性结果不是新概念理解的证明。

注意：前后半段包含不同随机任务，特别是 changing 的真实规律发生反转；不能把
前后差直接解释为学习进步。清空状态是更直接的机制干预，但状态不同也使后续
实际经历不同。本轮尚未做所有反事实路径的严格因果分解。

GRU 平均错误语义尝试从规则记忆的 0.510 次/任务减少到 0.318 次；混乱环境
成功率仍只有 69.58%，规则记忆为 70.00%，EMA 为 70.83%。减少错误尝试没有
自动变成更好的完成率。关闭求助后，GRU 成功率从 82.92% 上升到 83.85%，
效用从 0.5170 上升到 0.5294：当前求助策略没有表现出总体净收益。

A 阶段规律分布的新留出任务：A 阶段 GRU 95.00%，A＋B 回放后 96.25%；不回放 A 时为 95.42%。
平均值未显示旧规律能力下降，但这不是长期灾难性遗忘已解决的证明。遍历执行器
始终保留，测试中仍会调用；本轮没有学习新执行方法，也没有技能删除机制改动。

所选动作即时成功预测的 Brier（先在每个任务内平均，再对任务等权平均）：
GRU 0.19695，统计＋MLP 0.20197。两者选择
的动作分布不同，这些分数不能独立证明谁的校准更好。GRU 的随机探索平均消耗
0.1484 操作单位/任务，所有探索失败也计入成功率与总成本。

可能原因（尚未验证）：环境规律低维，显式统计已足够；随机行为下的回报回归
未直接优化信息价值；模拟教师经常不值得其成本；部分可观测失败证据稀疏。
不能仅从训练损失下降判断这些解释成立，也不能据此直接增大网络或追加规则。

## 工程验证与未实现项

83 项测试通过。审查前先用失败测试复现并修复三项问题：缺失会话仍可能被回放
接受、检查点重复经历改变状态、运行配置可偏离已封存协议。另补了探索决策核验。
独立只读复核未发现剩余阻塞问题；这些修复都发生在正式冻结之前。

这些哈希是本地一致性控制，不是防恶意开发者改动全部文件的签名认证。记录中的
verified 是可信宿主对已发生事件的断言，不是教师可信或意识存在的证明。

仍未实现：自由语言方法习得、自发设计实验、学习生成问题内容、开放网页搜索、
多教师选择、自动目标创造的神经机制、任意 Agent 状态的通用编码、长期自主参数
更新与主动遗忘、自主识别上下文切换、主观体验检验。原 Frontier Lab 保留但未扩展。

## 下一步与发布判断

当前结构作为实验结果保留，稳定 Axiom 接口维持原状。下一次研究优先检查求助的
信息/成本价值以及回报目标是否与行为改善一致，先与现有显式统计策略比较。
本轮不通过增加规则、增大模型或重新抽取测试种子来补救负结果。

作为研究 alpha，可以公开这些可运行、可反驳的证据；不应宣传“解决了方法适用
边界”或“已获得人类式理解”。安装、源码/数据完整性和发布检查见
[GitHub 发布说明](github-release.md)；[第三方接入与运行](cognitive-api.md)。
