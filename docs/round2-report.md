# Noscari Baby / AXIOM 第二轮报告

日期：2026-10-19。软件：0.1.0a2。协议先于实验固定，见 [round2-design.md](round2-design.md)。

## 结论

共同的语义失败之后，训练过的恢复选择器比固定遍历恢复更常成功。但动态评分特征的消融没有降低表现；与廉价求助启发式、LinUCB 和同经验记忆比较，也没有建立普遍优势。本轮证明可训练的逐步恢复闭环，不证明理解错误或类人纠错。

## 设计与信息条件

5 个种子 × 2 种教师条件（正确/部分错误），每个学习者 480 个训练任务。测试为 4 种布局 × 3 种帮助条件 × 30 个任务。9 组各 3,600 次测试，总计 32,400 次。每组先执行相同的语义尝试，失败子集均为 1,557 个任务；该子集不由后续策略选择决定。

训练轨迹使用均匀随机的可用动作，只记录实际执行动作的回报。标签为最终成功减去该决策之后的操作成本；已花费的语义前缀成本不进入该步训练标签，但计入完整任务指标。可训练对照使用同一批轨迹；测试期间参数冻结。没有把目标位置、布局类型或种子作为评分输入。

参数为每动作 20 个系数，共存储 80 个；共同前缀后语义动作不可用，该实验实际拟合遍历、搜索、请教三行（60 个系数）。初始语义方法仍由第一轮教学机制提供。MLP、LinUCB、ridge 等超参数沿用固定设置，未在最终测试集调参。

## 共同失败子集结果

操作数包括语义前缀与求助成本；综合得分为 success − (0.6+0.2×risk)×operations/budget。

| 策略 | 成功率 | 综合得分 | 平均操作数 | 教师调用/任务 |
|---|---:|---:|---:|---:|
| D_recovery | 91.39% | 0.4794 | 4.085 | 0.316 |
| fixed_fallback | 85.74% | 0.4047 | 4.279 | 0.000 |
| cost_heuristic | 89.85% | 0.4840 | 3.893 | 0.333 |
| memory | 90.69% | 0.4621 | 4.214 | 0.316 |
| LinUCB | 91.46% | 0.4778 | 4.102 | 0.349 |
| MLP | 90.04% | 0.4544 | 4.222 | 0.373 |
| frozen | 85.74% | 0.4047 | 4.279 | 0.000 |
| initial_context | 91.46% | 0.4812 | 4.075 | 0.317 |
| no_inquiry | 85.74% | 0.4047 | 4.279 | 0.000 |

**关键负结果：** initial_context 成功率略高于 D_recovery。这个消融只移除评分器的动态特征；动作掩码仍使用当前已访问菜单、余量和授权。因此它不是完全关闭反馈，也不能据此认定反馈不重要。当前数据不支持动态评分输入具有额外收益。

配对综合得分差 D − 对照，以 5 个独立种子的均值计算描述性 95% t 区间；不把同一模型的任务当作独立训练重复，也未作多重比较校正。

| 对照 | 差值均值 | 95% 区间 |
|---|---:|---|
| fixed_fallback | +0.0757 | [+0.0175, +0.1339] |
| cost_heuristic | -0.0038 | [-0.0458, +0.0383] |
| memory | +0.0174 | [-0.0155, +0.0504] |
| LinUCB | +0.0019 | [-0.0071, +0.0109] |
| initial_context | -0.0014 | [-0.0106, +0.0077] |

## 参数与接口证据

演示中，同一个观察下首选方法为 traverse → 仅记录后 traverse → 显式训练后 ask；系数 L2 改变量 0.251319。回滚摘要与初态完全一致。这是选择过的成功教师示范，只验证接口及行为变化，不能用来估计恢复成功率。

主实验全部 10 个学习者产生真实参数更新；训练/测试任务 ID 交集为 0；所有组测试参数不变。运行约 73.48 秒，CPU，API 费用 0。该时间来自本机，不是对用户 GPU 性能的估计。

已实现独立 RecoveryLearner 的 observe/suggest/teach/feedback/learn/save/load、回滚、撤销、删除和重放；反馈必须为可信宿主验证的完整连续轨迹。配置在重开时恢复，公开配置只读，不能将原权重静默套用到另一特征定义。

## 测试、审查与局限

当前合并代码 56 项测试通过（含 V0.2），原始输出见 `experiments/tests-a2.txt`。审查发现并修复：配置可变导致恢复语义漂移；无新菜单证据也能声称成功。两项先由失败测试复现，再修复并通过复核。模拟器原运行不产生这些无效输入，修复不改变既有数值结果。包安装及扫描证据见 `experiments/verification-a2.json`。

未实现自主创造新方法、任意软件交互、自然语言教师执行、自由语言表征训练或长期自我模型。MC 目标来自随机行为策略，不等于最优行动价值；训练与评估访问状态分布不同。当前动作空间及语义先验很小，失败样本的共同前缀限制了可辨识性。

预测误差日志是回报回归误差，不是概率校准证明；固定启发式分数也不是同单位的价值预测。5 个种子与这些玩具环境不足以支持广泛性能结论。

## 下一步

优先设计需要利用连续失败线索才能区分的匹配任务，并保持当前动作掩码与预算控制，检验动态输入是否有独立贡献。继续保留廉价求助、记忆和 LinUCB 基线。V0.2 动机实验独立运行，不用于掩盖本轮负结果。
