# Research Alpha 发布准备计划

2026-10-19；依据用户授权执行常规工程检查，公开仓库仍待用户确认。

1. 保留 alpha 1–4 原始归档、报告、模型和失败数据；冻结的认知模型三份源码不变。
2. 建立不继承开发环境依赖的虚拟环境，从发行版安装依赖和 wheel。在源码树外导入，重跑全部公开研究、工程演示及历史教师回答重放；比较完整指标和参数，不以 smoke 代替正式复现。
3. 将复现入口、判定方法和本地 CI 检查纳入发行版。CI 配置涵盖 Windows/Linux 与基础/认知组件；远程未执行必须明确标记。
4. 检查依赖解析、许可证文件、包内容、当前材料及所有本地历史归档中的凭据和隐私；扫描发现只报位置与类别，保留人工审查记录。无 Git 历史时如实标注，不能宣称已检查不存在的提交。
5. 更新 README 中 Noscari 架构与 Baby 模型的边界、全部主要对照和失败。新发布准备版本只改发布工具与文档，不改变历史实验算法。
6. 提交主动求助信息价值的实验设计和停止条件；本轮不实现新研究、不重新调参。
7. 复核、构建、保存发布清单与哈希。确认尚无外部公开行为，提交用户审阅。

发布门槛是可检查、可复现且诚实的研究原型，不是 GRU 超过简单方法。若复现或隐私检查出现无法解释的问题，保持发布阻塞并报告，不补写成功结论。
