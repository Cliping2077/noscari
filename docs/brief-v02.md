# Noscari Baby — 正式研发补充 V0.2

来源：用户于 2026-10-19 提交的研发补充指令。本文归档其约束和验收要求；
本补充与此前 V0.1 同时生效，不替代原计划。执行映射与最小实验协议见
[v02-plan.md](v02-plan.md)，实际结果见 [v02-report.md](v02-report.md)。

## 长期方向与保留目标

研究能持续感知、主动求知、形成内部目标，并通过经验改变自身认知和行为机制的
人工学习主体。它可使用外部 LLM 的语言与专业能力，但自身必须有真实、可观察、
可训练的学习机制。允许初期知识少、能力弱、提出简单问题和失败；检验经历能否
带来成长。无需发明全新的学习原理，也不要求第一代具有人类水平能力。

V0.1 的经验记忆、独立技能积累、多候选、主动索求、内部可塑性、可替换 LLM
接口、可重复实验、基线、遗忘及回滚、安全与发布门槛全部保留。

## Motivation Core

- 陌生现象、预测矛盾、知识缺口或学习机会可以触发问题，不必等待外部任务。
- 问题与探索目标跨任务、会话和模型切换保存，可暂停、重启、调整或放弃。
- 研究经验、学习进展、环境变化和内部状态如何形成可变的探索倾向。
- 研究自主尝试、检索、调用模型、请教用户、观察示范和设计实验的选择。
- 经验可改变注意、问题选择、记忆唤起和行动偏好；至少部分探索机制必须可训练，
  并检验参数变化是否带来可迁移的行为变化。
- 采用轻量、可解释、可独立测试的机制，不训练大型语言模型。

## 主观体验的开放研究

不预设 Baby 一定会、或永远不可能产生主观体验。允许讨论和实验计算假设，
区分功能性行为、内部计算机制与主观体验。拟人语言、模拟情绪或行为测试均不能
单独证明意识。不得通过制造痛苦、恐惧、依恋或胁迫追求疑似意识现象。
保留研究接口、日志和伦理评估空间；意识研究不是第一版发布条件。

## 双实验体系

Core Lab 严格研究持续学习、记忆、联想、求助、内部更新、迁移与遗忘：提前明确
假设、基线、预算、种子和原始日志，记录失败与不确定性，验证新经验是否改变参数
与后续行为。

Frontier Lab 允许小规模、大胆的探索：兴趣分化、搁置问题的自发重拾、无任务时
寻找学习机会、对知识和学习过程提问、持续自我表征及循环认知。真实记录结果，
区分演示、猜想和证据，不事后改写解释制造成功。值得研究的现象再进入 Core Lab。

优先候选 A：相同初态、不同经历形成可修正偏好。B：相关线索触发未解决问题，
无需明确提示。C：识别对自身成功条件的预测缺陷，主动求助或实验。允许依据调研
与结果调整；本增量只实施 A，B/C 不默认为已实现。

## 资源、权限和交付

个人维护；RTX 4080 Laptop 12GB。优先已有 Core 最小学习闭环，动机模块先做
最小接口和机制。Frontier 与稳定核心隔离，失败不能破坏主系统。无昂贵常驻多 LLM
系统；网络、API、文件、设备均受权限和预算约束。支持暂停探索、删除个人记录、
撤销授权。无需机器人，也不从零训练语言。

检查现有工程并报告实现与设想；更新研究路线图；定义最小动机状态与接口；建立
两类实验目录和记录规范；完成至少一个自主目标或主动提问实验；验证真实更新，
说明是否改善学习或行动；标明认知与意识未知问题。继续使用现有工程，禁止无限
扩张第一阶段范围，以可运行代码、真实训练和实验为依据。

**Be rigorous about evidence. Be fearless about hypotheses.**
