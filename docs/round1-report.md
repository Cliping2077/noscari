# AXIOM 第一轮研究与工程报告

日期：2026-10-18。阶段：0.1.0a1，本地研究原型。

## 结论

已建立可安装的离线学习核心，并验证教学记录与参数更新分离：一次受验证的示范可改变内部线性评分器，以及相同观察下的首选方法。冻结参数对照保持原行为，回滚能恢复原始参数。

这说明最小参数学习链路成立，**不说明已实现类人学习、自动方法创造或优于强基线**。主实验中 AXIOM 与记忆检索、LinUCB、MLP 的差异没有给出明确优势；固定候选策略的平均成本综合得分更高。

语义执行方法、词表、回退遍历和特征均为预先实现。教学让该方法进入技能库，并产生评分训练样本；没有从教学语言中自动编译出新的技能。学习器是 4×10=40 个可训练系数的线性模型。

## 一次教学，与多次反馈实验分开

- 样本：1 次成功教师示范；测试为 240 个未见任务，没有其他训练反馈。
- 记录前/记录后参数摘要相同：`48ecd7fc245a008d9dd42a90a77a79d0d45266fc383bb291db78d2479e071417`。
- 显式 learn 后摘要：`e6c04eadf9da853e0415f76b0b553e6b05cf0da92696ababe346bee0b0710302`；L2 参数差值 0.306336。
- 示范情境首选：traverse → semantic；traverse 和 semantic 同时保留。
- 测试成功率：91.25% → 93.75%。这是单一教师样本的描述性结果，没有多教师统计推断。
- 回滚摘要与记录前精确相同。示范不包含评估任务路径；目标可见文本使用固定类别前缀，是明显的语义先验。

原始证据：`experiments/one-demo/demo.json`、`checkpoint.json`、`events.jsonl`。

## 主实验

5 个独立训练种子；每个种子分别采用正确教师/部分错误教师，均有 1 次示范与 240 条随机选择宏动作所得的真实执行反馈。每组 2,400 次测试，9 组共 21,600 次。4 种布局 × 3 种求助条件；各组使用相同任务、预算和预采样提示噪声。

## 分布变化与保持

120 个语义布局训练任务后，再提供 120 个混乱布局任务。以下为每个条件 300 次测试的汇总。

| 训练状态 / 测试布局 | 成功率 | 综合得分 | 平均操作 |
|---|---:|---:|---:|
| old_trained/semantic | 100.00% | 0.8886 | 1.007 |
| old_trained/scrambled | 86.33% | 0.4642 | 3.857 |
| latest_only/semantic | 87.00% | 0.4702 | 3.627 |
| latest_only/scrambled | 91.33% | 0.4930 | 4.013 |
| full_replay/semantic | 99.00% | 0.8480 | 1.383 |
| full_replay/scrambled | 86.33% | 0.4651 | 3.840 |

只用新数据重新拟合时，旧语义任务成功率从 100% 降为 87%；完整回放为 99%。但完整回放在新混乱任务上的成功率为 86.33%，低于只用新数据的 91.33%。保持旧行为与适应新分布存在权衡，本轮没有解决这一问题。

## 失败与科学限制

- AXIOM 的语义尝试中，46.20% 首次猜测错误；错误迁移指标不因后续遍历成功而消失。
- 混乱/遗留布局的隐藏分类规则未暴露给模型；相同可见菜单可能对应不同正确位置，当前观察不足以区分。单靠增加评分器容量无法消除这种不确定性。
- 部分错误教师的演示实例仍成功，错误位于未演示类别。一次观察不足以验证整条方法规则；不能把 verified 的单例结果解释为方法普遍正确。
- 固定候选策略 C 更省操作；下一轮首先检查学习目标、情境特征与求助成本，而不是增加 Agent 数量。
- 词表和类别先验是手工提供的。未见名字和布局不等于未见概念，更不等于跨软件、跨领域迁移。
- 学习的是初始宏动作排序；错误后的回退由固定执行器完成。没有证据表明学习器自行学会了反思、诊断原因或选择回退时机。

## 工程验证、资源与数据

- 最终自动化测试：32 passed。记录位于 `experiments/tests.txt`。无剩余测试失败；包含安全、导入、技能版本、更正、确定性对照、离线网络守卫与分布变化探针。
- sdist 与 wheel 构建成功；用 `--no-index --no-deps` 将 wheel 安装到源码目录之外，实际完成离线教学演示及 242 条事件的检查点恢复。凭据模式扫描未发现匹配。独立审查提出的四个问题均已解决。
- 首轮失败记录：缺少实现导致导入失败；Windows 沙盒默认临时目录不可写；asyncio 初始化本地 socketpair 阻塞；审查复现了导入验证绕过、旧技能反馈混用、失败更正破坏原状态，以及后续验证不能激活未验证示范的回归。这些问题均有修复或明确的测试环境适配。
- SQLite + 可重放 JSONL；可查看、修正、撤销教学；可信本地 JSON 检查点，无 pickle；权限过滤不能被评分覆盖。隐私删除的边界见 SECURITY.md。
- 主实验壁钟 22.83 秒，设备 CPU；GPU 显存使用需求为 0，商业 API 调用/费用为 0。该成本不包含本次研发对话、资料检索、依赖下载、电费。
- 所有策略选择延迟有逐条记录；D/MLP 的拟合时间记录在 parameter_audit.json。B/LinUCB 的独立准备时间未单独计量，不能从现有日志推断完整训练成本优劣。
- 参数冻结检查全部通过：True；训练与测试任务 ID 交集：0。
- 修复前后完整运行的 aggregate 指标一致；发布证据使用修复后的 `experiments/validated/`。UUID、日志 ID 与壁钟可不同。

## 已实现与未实现

已实现：包接口 observe/suggest/teach/feedback/learn/save/load；事件与技能记录分离；版本来源和结果追踪；40 系数可训练排序器；多个候选；受权限和预算约束的求助宏动作；重放、精确回滚、记录更正/删除；演示、基线、消融、保持探针；异步可替换能力协议；README、MIT、贡献、安全、测试与 CI 配置。

未实现：从自由语言示范生成新方法；学习语义表征；独立信念修订；候选执行中交错生成、组合、失效再激活；跨任务持续目标/子目标；自动选择探索任务；真实网络搜索、人类交互偏好学习；视觉；长期大规模持续学习；多进程存储；生产级权限沙盒；形式化遗忘。保留旧技能版本，但当前默认排序器只训练最新语义版本；不自动选择多个历史语义版本。

CI 配置已提供，尚未远程执行。未向 GitHub、PyPI 或其他平台发布。真实商业 API 适配和模型权重训练均不在本轮范围。

## 下一轮优先级

1. 先补可辨识的环境线索与校准测量：区分“语义方法不可靠”和“当前观察不足”。保留固定策略、记忆基线、LinUCB，设计独立验证集后再调参。
2. 将目前手写的回退拆成可观察的决策步骤，检验是否能从错误结果学习“何时换方法、何时请教”，比较同预算固定恢复策略。
3. 做一个有限的教学方法表示：允许教师提供可验证、可执行的声明式新规则，先在沙盒中检验，再决定是否巩固。用部分错误教师和撤销验证闭环。不要直接让自然语言内容获得执行权限。
4. 若前三项有证据，再扩展到一个真实软件的受控离线任务。暂缓 Web 产品、多 Agent 编排、从零语言训练与大型认知模块。

目标不是为了新颖性发明算法，而是逐项接近“能被教会、会试用、能纠错、能迁移”的学习行为；每一步仍须给出可观察证据。
