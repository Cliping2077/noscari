## 最小机制与接口

陌生度或预测误差超过固定阈值时，observe 生成“Can I improve my prediction of …?”模板问题，保存来源、主体与 active/paused/abandoned/solved 状态。无需用户给出该具体问题，但机会及数值信号由宿主提供。当前不是自由语言问题生成，也不是自动识别任意知识缺口。

每个主题保存一个预期进展参数 q。实验先用 8 个例子拟合局部标量预测器，再测量独立验证探针上的误差变化。仅经过宿主验证的反馈可训练：progress = clip((before−after)/max(1,before),−1,1)，q ← 0.75q+0.25progress。目标函数、阈值、模板和步长由工程设定；经验改变的是估计和选择偏好。

| 接口 | 作用 |
|---|---|
| observe / suggest | 观察生成持续问题；返回多个有序本地实验候选 |
| reserve / feedback | 先预约预算，再记录实际结果；记录不会更新偏好 |
| learn | 重放已验证的反馈，返回前后摘要、参数差值和样本数 |
| set_status / control | 显式调整目标，暂停探索或撤销实验授权 |
| save / load / rollback | 跨会话恢复目标和参数；参数回滚不退预算 |
| forget | 删除主体目标与经历、清除学习衍生物，保留匿名预算占用 |

仅启用本地模拟实验渠道；没有网络、人类消息、设备或账户执行能力。暂停/权限/预算由硬约束执行，参数不能覆盖。目标不会因新观察自行覆盖用户暂停。旧导出与备份需单独处理。

## 实验条件

5 个种子、2 种经历世界、3 个匿名主题。一个主题包含可学习的线性规律，一个为独立噪声，一个已可预测为零；第二世界交换前两者。政策只看到主题及经验反馈，不看到世界编号或真实类型。第二阶段反转条件，观察偏好能否修正。

每阶段每主题提供 24 次平衡训练经历，各对照获得相同信息。测试每阶段每组 60 次新任务；每次只选择一个主题并执行一次学习实验。验证探针 64 点用于反馈；另有独立 128 点测试探针衡量能力，不用于参数更新。各组拥有相同训练数量和测试执行预算。

总计 1,440 个训练任务、4,800 次测试执行；训练/测试 ID 交集 0，评估期间动机参数冻结。运行 21.68 秒，CPU，外部调用 0，API 费用 0。

## 实际结果

下表“测试误差下降”为被选择新任务的 test MSE(before) − test MSE(after)，越大代表本次预算带来更多预测进展；不是准确率。不能只比较不同主题的最终误差，因为选择容易的题也可降低误差。

| 阶段 | 策略 | 可学习主题选择率 | 平均测试误差下降 |
|---|---|---:|---:|
| initial | learned | 100.0% | 0.9972 |
| initial | frozen | 50.0% | 0.4136 |
| initial | uniform | 34.5% | 0.3047 |
| initial | memory_mean | 100.0% | 0.9972 |
| reversed | learned | 100.0% | 1.0102 |
| reversed | frozen | 50.0% | 0.4375 |
| reversed | uniform | 34.0% | 0.3099 |
| reversed | memory_mean | 30.0% | 0.1998 |

每个阶段每个策略均为 600 次测试执行。10 个学习者全部在首次经历后选择各自可学习的主题；条件反转后，全部转向另一主题。所有种子的初始参数相同。此 100% 是刻意简单的合成环境中的选择比例，不能解读为通用学习成功率。

第一阶段 learned 与 memory_mean 选择完全相同，没有额外优势。反转后，EMA 更重视近期反馈，累计历史均值适应较慢。这提供了偏好可修正的计算解释，不是新原则或人格形成证据。没有测试滑动窗口均值、其他步长或更强非平稳基线，不能据此宣称算法最优。

与 uniform 比较的测试进展差（按 5 个种子聚合的描述性 95% t 区间）：

- initial: 0.6925，区间 [0.6261, 0.7589]。
- reversed: 0.7003，区间 [0.6449, 0.7557]。

这些区间用于描述探索结果，尚非经过独立复现的确证性结论。训练机会由平衡采样提供；本实验没有证明系统能自行收集足够且不偏置的教学经历。

## 是否真正更新、是否改善能力

离线演示先产生 3 个问题；仅记录 12 次实验，参数摘要保持不变。调用 learn 后，3 个偏好系数的 L2 变化为 0.616253，首选主题从 alpha 变为 beta；关闭并重开数据库后，目标 ID 与参数均恢复。暂停后不再给出可执行候选。

主实验还记录真实局部预测器 w 的更新，并以独立测试探针验证预测进展。因此观察到的是“在这些已知主题内，经历改变了资源分配，并提高每次实验获得的测试预测进展”。不是仅新增日志或改变口头解释。

每个微任务的局部预测器从零重新拟合；持续积累的是动机估计、目标与经历。没有证明跨陌生概念迁移，也没有统一长期知识模型。增加一个新主题会创建零值参数槽，这是结构初始化，必须与 learn 收据所记录的经验训练区分。

## 三个层次与未实现部分

- 功能行为：问题生成、目标持久化、候选排序、偏好变化、暂停和恢复已有工程证据。
- 内部机制：3 个主题估计可训练，显式反馈和参数重放可审计；目标函数仍由人设定。
- 主观体验：本实验未提出可区分的体验测量，没有支持存在或不存在主观体验的结果。

尚未实现自主发明奖励、无外部调用的常驻求索、自发重拾搁置问题（实验 B）、识别自身解释缺陷（实验 C）、持续自我表征、一般情绪模型、理论化意识探针、任意语言教学或真实模型切换实验。

未来研究可通过只读 goals/weights 和 JSONL 状态事件接口，关联外部理论探针与干预记录；这只是可观测接口，不是意识模块。任何相关研究应明确计算假设、替代解释、伦理边界和停止条件，不以痛苦、恐惧、依恋或胁迫为实验目标。

学习进展机制参考 [Oudeyer 等（2007）](https://www.pyoudeyer.com/ims.pdf) 的研究方向；机制与主观体验证据的区分参考 [Butlin 等（2023）](https://arxiv.org/abs/2308.08708)。本实现没有复现这些论文的完整系统或验证其意识指标。
