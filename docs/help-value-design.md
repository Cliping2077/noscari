# 下一轮 Core Lab 设计：主动求助的信息价值

2026-10-19，设计稿 help-value-v1。**本轮仅设计，未生成新测试集、未训练、无新结果。**
复用现有菜单环境、三种动作、显式统计、线性模型、context MLP 和可选 GRU；不增加网络、搜索服务、教师角色或动机模块。实施前将本设计、具体生成器及分析代码一起冻结。

## 研究问题与已有证据

当前 cognitive-v1 中 GRU 成功率 82.92%，禁止求助消融 83.85%，平均效用分别 0.5170、0.5294。它们是相同任务上的策略结果，**不是每次提问的因果效果**：禁止动作会改变轨迹、探索分支、后续反馈和内部状态。不能把差值全部归因于某一个错误教师，或从成功求助的子样本推断“值得问”。

当前 `ask` 消耗预算，可能无答复或返回错误位置；有答复时还会打开建议菜单。它不是免费增加信息。选择器训练目标是任务内 Monte Carlo 回报，跨任务持续状态参与决策，但目标不直接奖励未来任务受益。当前模型没有提问次数奖励，也没有自动学会一种新的执行技能。

因此首先区分三个可测量层次：

1. 当前任务收益：更快完成、避免一次失败，与求助占用预算的损失。
2. 跨任务适应：一次真实反馈改变显式统计或递归状态，帮助以后判断适用条件。评估期间不改权重，这只能称状态适应。
3. 持久参数学习：训练回放导致选择参数变化，恢复检查点后在陌生会话中改善选择。参数差异本身不是收益证据。

情景记录、显式统计、GRU 隐状态、慢参数分别记录；教师回答被存储不等于通过验证，更不等于参数已经更新。

## 假设与反证条件

| 编号 | 可检验假设 | 怎样否定/限制它 |
|---|---|---|
| H1 | 当前负效应至少部分来自求助成本、无答复和错误建议占用操作机会 | 配对分支中移除收费或替换为正确当前提示后仍无变化，就不能用该因素解释损失 |
| H2 | 在共享潜在规律的后续任务中，求助后获得的已验证反馈存在正的未来价值；独立重采样的环境中该价值更小 | 相同未来预算下不保留任何状态也有同样收益，或保留状态并未改善未来无求助表现，均不支持此解释 |
| H3 | 使用会话回报训练现有 context MLP，可比任务内目标更合理地分配求助，并超过简单统计策略 | 预先指定的主要效用差不达到标准，则保留简单方法，不升级网络 |
| H4（次要） | 方法能从拒绝/错误中修正判断，又能在环境改善后重新尝试；不会由一次拒绝永久关闭渠道 | 改善后的固定观察窗没有重新尝试或效用恢复，记录为适应失败；不手写“拒绝后重试”规则补救 |

这不是假设所有求助都应当增加。零次求助在部分条件中可能合理。高不确定性也可能来自不可消除的随机性；不能把预测误差、话语中的“好奇”或问题数量当成学习收益。

## 第一阶段：旧结果的因果诊断

只使用训练/开发会话定位实现问题，之后才冻结新的确认性留出集。旧 cognitive-v1 测试集已公开，分析它只能标为事后诊断。

因果诊断的决策点固定为**会话第一个任务的第一次决策**，采样不取决于策略是否想问或任务是否成功。若该点未授权或不可支付，记录“不具备诊断条件”，不换一个后来更有利的点；报告排除数量和原因，主要策略评分仍包含这些会话。保存完整可见历史、模型状态和随机种子，评估器复制分支：`ask` 与该模型最高分的非求助动作。之后均执行同一个冻结策略，继续收到各自真实反馈。

评估器持有隐藏菜单、教师质量和模拟器随机结果；这些信息只用于配对和评分，不进入策略输入、问题模板、回放训练或能力标签。按 `(会话, 任务, 渠道, 尝试编号)` 固定外生随机数，避免多调用一次随机数就改变全部后续任务。

分支诊断预先包括：原始求助、相同回答但免收求助费、正常收费但当前答案正确、收费且没有回答。免收费与正确答案分支是**评估干预**，不作为学习策略，不计入公平基线排名。记录实际菜单打开成本，不将教师直接执行任务的收益当作 Baby 的掌握。

对该点之后的未来任务窗 H=1、8、23（不含当前首任务），报告：

`Δ当前 = U当前(求助分支) − U当前(非求助分支)`

`Δ未来(H) = Σ U未来(保留求助经历) − Σ U未来(保留非求助经历)`

`Δ总(H) = Δ当前 + Δ未来(H)`

`U = 完成指示 − 0.6 × 实际操作成本 / 该任务预算`，沿用旧效用以减少自由选择；另报原始成功数、费用和时间。当前项已经扣费，不再次重复扣费。不用测试集选择折扣率或成本系数。

为分清当前答案与未来适应，两分支在后续任务获得相同新预算、相同任务序列，并在一项诊断中禁用后续求助。另将两分支的记忆/统计/隐状态分别重置到共同的分支前状态，测量收益是否消失。当前菜单打开状态不能跨任务带入。状态移植只用于评估消融，不给训练者提供反事实标签。

**环境是否确实存在可学习信息是前置检查。** 先保留现有“一次位置提示”，检查其执行反馈是否有跨任务价值；若没有，不悄悄把教师改成万能技能教师。报告该环境无法测量预期的未来教学收益，停止这一确认性问题。未来若另研究可复用方法教学，需独立版本、单独冻结，不能混入本轮结果。

## 第二阶段：同结构、不同学习目标

只有第一阶段的可测量性检查通过，才进入训练比较。主要改动仅为**回报作用范围**：将任务内已选动作回报改为当前任务余下回报加同会话剩余任务回报，使用有限长度、折扣 1 的可观察回报；优化器、特征、容量和验证规则保持不变。选择器依旧只看当前和过去，不能读取未来奖励。未来轨迹可在训练回放结束后成为监督目标，这是离线训练，不是执行时偷看未来。

共享经验由**现有 EMA 统计策略＋20% 均匀探索**采集，保留非求助、失败、拒绝和授权限制。统计策略的形式和超参数在开发阶段固定；会话内统计只从真实反馈更新，因此后续行为能够利用前面求助所得信息。所有可训练方法拿到相同的已选动作序列、记录的行为概率和相同更新次数上限。测试学习策略的探索仍为原有 5%。

完全随机行为虽然能提供动作覆盖，却不会用新增信息改变未来行为；在每任务预算重置的环境中，直接延长这种行为的 Monte Carlo 目标主要增加未来回报噪声，不能据此学习信息的决策价值。因此旧均匀采集只作为预先声明的**信息不被利用对照**，不作本轮主训练集。主要比较不以额外网络解决这个问题。

会话回报对应数据收集策略下的回报，并非最优策略 Q 值；策略改变后的分布偏移仍是限制，不能称为已经解决长期信用分配。若统计行为在开发阶段也未能利用信息改善后续行动，应按前置条件停止，不依靠增加数据掩盖目标缺陷。

主要对照如下；不因留出结果新增基线或改参数：

| 方法 | 信息与训练 |
|---|---|
| 禁止求助 | 原有 rule-memory 语义优先＋遍历；同预算，作为低成本参照 |
| 总是先问 | 仅在授权且可支付时问一次，剩余用相同原语；无隐藏教师标签 |
| 固定阈值 | 基于剩余预算与可见价格，阈值只用开发集挑选 |
| EMA 贪心 | 现有按动作/类别累计真实反馈的统计策略 |
| 统计＋线性任务目标 | 现有公开观察和历史统计，任务内回报；轻量上下文基线 |
| 统计＋线性会话目标 | 相同数据、统计和容量，仅改变回报跨度；强简单基线 |
| context MLP 任务目标 | 原有结构、优化器与容量 |
| context MLP 会话目标 | 唯一主要候选；不增加隐层或输入真值 |

GRU 的任务/会话目标比较只作为预先列出的可选次要复制，不能替换主要比较或据其较好结果挑选赢家。若简单方法已经回答问题，停止，不为保留 GRU 添加复杂性。

同信息并不等于同表示：简单统计明确提供工程统计摘要，GRU 自行压缩相同反馈。价格、预算和授权是可见约束；“老师可靠”“菜单合理”“环境刚刚改变”“当前是共享规律条件”等隐藏标签不能给任何学习基线。

探索概率固定为原有 5%，学习策略之间相同；固定规则端点没有随机探索，作为明确标记的参照。禁止求助属于权限屏蔽消融，不要求其人为花掉节省的预算。报告探索花费与收益，不加入提问奖励。一次拒绝不能修改用户授权或永久禁用渠道。

## 数据、预算和分析冻结

- 训练种子 0–4，开发种子 100–101，确认测试种子 1000–1004；采用新命名空间 `help-value-v1`。最终以任务与会话 ID 交集检查确认分离，种子不同本身不构成无泄漏证明。
- 每训练种子 64 个会话、每会话 16 个任务，总计 5,120 个训练任务；开发每种子 16 个会话。五个模型训练种子不能把同一会话的几十个步骤当成几十个独立复制。
- 确认集每种子 32 个会话，每会话 24 个任务，总计 3,840 个测试任务。平衡现有合理/混乱/部分规律/变化四类；教师答复率和正确率在模拟器内部随机，价格 1/3 与任务预算 4/6 为可见条件。共享规律与逐任务重采样各半，条件标签只给评估器。
- 主要策略评分是完整 **24 个任务**的会话累计净效用，与前述因果分支诊断分开。分支诊断的 H=1、8、23 只指首任务之后的任务；不能把 24 个后续任务塞进剩余 23 个任务的会话。无后续求助窗口为次要诊断，不能事后选最好窗口作为主结论。
- **唯一主要比较**：context MLP 会话目标减去统计＋线性会话目标，按五个训练种子的配对均值计算 t 区间（自由度 4）。同时报告各种子、所有分格与会话聚类 bootstrap 敏感性分析，不把 bootstrap 当新独立样本。
- 继续复杂方法的实际门槛：每任务平均净效用提升至少 0.01，且主要 95% 区间下界大于 0；与 EMA、固定策略及任务目标的全部结果仍须公布。阈值是研究决策标准，不是意识或智能标准。
- 该主要比较通过也不是保留 MLP 的充分条件：若 EMA、规则记忆或开发集固定阈值在确认集上有更高的平均净效用，默认保留简单策略；若区间无法区分优劣，同样不声称复杂模型占优。禁止只击败较弱线性对照就宣称架构优势。
- 补充：成功率、求助次数/答复率、错误提示损失、探索费用、首次错误后适应时间、原遍历保持、未见会话迁移、无教师未来测试、参数与状态变化。能力预测使用统一的固定探针任务评估，不能用不同策略选中的动作分布直接判校准赢家。
- 验证权重冻结、重放候选/行动/反馈/隐状态，确认测试反馈只可更新约定的快速状态，不进入稳定参数。最终以无求助、全新会话和重置状态的测试隔离慢参数贡献。
- 限制：零商业 API、CPU 优先；每完整协议 CPU 墙钟上限 30 分钟、内存 4 GB、单种子最多 160 训练 epoch。只允许一次开发协议冻结后正式运行；修复实现错误须保留旧运行并增版本，不能静默重跑覆盖。若机器比参考环境慢，记录资源阻塞，不降低正式样本数冒充完成。

## 停止条件

1. 发现教师真值、未来目标或反事实奖励进入学习者：立即停止，保存日志，修复泄漏后另行冻结，不发布该次能力结论。
2. 在开发配对探针中，保留经历相对重置没有可检测的未来收益，并且评估正控制也无法体现信息差：停止“未来学习价值”训练，先报告环境/测量不支持该问题。不得为造出收益改教师答案。
3. 主要结果未达到上述区间与实际效应门槛：本轮以负结果完成；选择简单基线作下一轮默认，不追加新网络或适用条件手写规则。
4. 当前成功增加但未来无帮助任务没有进步：只声称外部帮助提高当前表现；不声称 Baby 获得新能力。
5. 求助总成本上升却无净效用/迁移收益，或旧技能明显受损（预定可靠旧分布成功率下降超过 3 个百分点）：记录代价与失败，不以“更主动”掩盖。
6. 资源上限、日志无法重放、预算不一致或数据无法匹配：停止运行，保留部分结果，不把未完成结果计为成功。

交付为冻结协议、共同经验数据、全部基线、状态/参数变化、固定首会话轨迹及失败分析。它研究有限环境中的信息获取与条件选择，无法检验主观好奇心、主体体验或意识；这些仍是开放问题。

## 理论依据与适用边界

[Russo 与 Van Roy，2014，Information-Directed Sampling](https://proceedings.neurips.cc/paper_files/paper/2014/hash/90720a2fcc41f9332e6a1558da327089-Abstract.html) 将单期机会损失与关于最优动作的信息量共同考虑，为“获取信息也有代价”提供依据。本轮不照搬其性能保证；菜单任务、非平稳教师和有限回放不满足同一理论设定。

[Mavor-Parker 等，2022，How to Stay Curious while avoiding Noisy TVs](https://proceedings.mlr.press/v162/mavor-parker22a.html) 展示随机噪声会误导基于预测误差的探索。这支持把可迁移的实际收益与纯粹惊讶分开；不意味着其方法已经在 Noscari 上得到验证。本轮不增加该文的专用网络。
