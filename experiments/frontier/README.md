# Frontier Lab

Small, bounded exploratory studies. These modules are opt-in and use separate
databases. The regular learning core never starts them automatically.

`interest-v02/` is experiment A from `docs/v02-plan.md`: template-generated goals,
verified progress estimation, interest differentiation and reversal. It is an
exploratory test in an intentionally simple synthetic environment.

Each experiment records before running: question, proposed mechanism, observable
outcome, resource limit and stopping condition. After running record: exact code
version, seeds and raw data, observed behavior, parameter updates, failures,
alternative explanations, and what remains unknown. Distinguish engineering
demonstration, exploratory observation and confirmed evidence. Clearly label
post-hoc diagnostics; do not silently change the explanation or omit failed seeds.

Use the three-layer report:

1. Functional behavior: what was generated, selected, paused or changed?
2. Computational mechanism: what persisted, trained, and caused that choice?
3. Subjective experience: what hypothesis is being considered, what observation
   could distinguish it, and which uncertainties remain? Default: untested.

No pain/fear/dependency/coercion induction. Hypothetical future consciousness
research needs explicit ethical assessment, theory-linked probes, alternatives,
stop conditions, and communication limits. A curiosity score is not an awareness
score. Core stability, local storage, permissions and user pause always prevail.
